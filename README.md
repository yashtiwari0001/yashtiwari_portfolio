# Yash Tiwari Portfolio

Welcome to my personal developer portfolio! This project is built using **React.js**, **Vite**, and enhanced with **React Bit** for modular and reusable component-based development. It showcases my skills, projects, and professional experience in a modern and interactive way.

## 🚀 Features

- **Modern Tech Stack**: Built with [React.js](https://reactjs.org/) for UI development and [Vite](https://vitejs.dev/) for lightning-fast development and build tools.
- **React Bit Integration**: Utilized [Bit](https://bit.dev/) for sharing, composing, and reusing prebuilt and custom components efficiently.
- **Responsive Design**: Fully responsive layout optimized for desktops, tablets, and mobile devices.
- **Project Showcase**: Interactive cards to highlight key projects, with images, descriptions, and links to live demos or GitHub repositories.
- **Skills Section**: Lists key programming languages, frameworks, tools, and technologies I’m proficient in.
- **Experience & Education**: Timeline-style display of professional experiences, internships, education, certifications, and more.
- **Contact Section**: Includes a contact form and social media links to connect with me easily.
- **Custom Components**: Leveraged both custom and prebuilt Bit components for faster development and better scalability.

## 📦 Technologies Used

- React.js
- Vite
- ReactBit
- HTML5 / CSS3 / JavaScript (ES6+)
- Git & GitHub
